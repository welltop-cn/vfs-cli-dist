# vfs-cli-dist

Public distribution repo for **vfs-cli** — hosts release binaries and the installer.
Source code is private at `welltop-cn/vfs-cli`.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/welltop-cn/vfs-cli-dist/main/install.sh | sh
```

Binaries are published to this repo's [Releases](../../releases) by the source repo's CI on every `v*` tag.
